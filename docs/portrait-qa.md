対象は、全20場面と第7・8・11場面の二つ目の読み位置を含む、23箇所の英文である。PDFから独立に抽出した照合データを使い、原文、句読点、固有名詞、順序を実際のHTMLと照合する。[PDFの照合データ](../tests/fixtures/pdf-oracle.json)

## 再現方法

```sh
npm ci
npx playwright install chromium webkit
npm run typecheck
npm run build
npm test
```

Playwrightは配布用の `dist/` をGitHub Pagesと同じ `/one-sky-many-stories/` にマウントする。iPhone 16相当のWebKitで393 × 852、iPad Pro 11相当のWebKitで834 × 1194、デスクトップChromiumで1440 × 900の表示を調べる。横向きではPDFから抽出した横長挿絵を、縦向きでは描き直した20枚を選ぶ。[ブラウザ設定](../playwright.config.ts)

公開後は、同じコミットのファイルが手元にある状態で次のコマンドを実行できる。ブラウザはログイン情報も保存済みキャッシュも持たない新しいコンテキストで起動する。

```sh
PLAYWRIGHT_PUBLIC_URL=https://belltreetech.github.io/one-sky-many-stories/ npm test
```

## 検査内容

- **原文と配信画像。** 各場面のDOMに原文が一度ずつ現れることを検査する。第7・8・11場面では両方の読み位置を検査する。画像はブラウザでデコードし、URL、種類、寸法、配信バイトのSHA-256を確認する。望遠鏡の星野と神話の丘の補助画像も照合する。
- **操作と読み返し。** 日本語の開始から最終場面の「最初へ」まで、本文や操作が重ならない位置で通読する。逆送り、高速スクロール、画面の高さ変更、縦横回転、200%文字拡大、動きを減らす設定の切り替え、音声を使えない状態を調べる。
- **絵の動き。** 七姉妹の場面で読者が止めたカメラの変位と、髪・袖・雲の残りの動きを別々に測る。望遠鏡の星野は逆送りで丘に戻ることを確認する。神話の入口は途中で止め、二組の姉妹が同時に見えず、人物のいない稜線がつなぐことを確認する。
- **読みやすさ。** 折り返した本文の各行について、文字を一時的に透明にして、画像・グラデーション・半透明レイヤーを合成した後の画素を取得する。実際の文字色と背景色からコントラスト比を算出し、行の内部の最小値を4.5:1以上とする。文字のアンチエイリアスは計算に含めない。[測定コード](../tests/readability.ts)
- **失敗時の表示。** 壊れた縦絵を返すと元の横長挿絵に戻り、壊れた補助画像を返しても本文を読めることを試す。Canvasを使えない状態でも最終場面に到達できる。日本語の音声操作はWeb Speech APIへの命令、読み上げる英文、一時停止・再開・取り消し、エラー後の表示を模擬音声で確認する。

通常の実行では `artifacts/screenshots/` に両端末の場面写真・コントラスト測定結果を保存する。公開URLの実行結果は `artifacts/public-portrait-qa/` に保存する。[全編の通読と照合](../tests/reader.spec.ts)・[縦絵の演出と異常時の検査](../tests/portrait.spec.ts)・[読み聞かせと音声の検査](../tests/read-together.spec.ts)

## 実機で確認する事項

WebKitの端末エミュレーションで画面寸法、読書操作、HTML・CSS・Canvasを検査できる。物理端末の切り欠きや指で払ったときの感触、搭載音声の音質・発音、連続利用時の発熱と消費電力は、実機での確認事項となる。
